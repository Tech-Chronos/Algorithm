### 2. 解题思路

> 滑动窗口的题目考虑三个步骤：
>
> - 何时进窗口
> - 何时出窗口
> - 何时更新结果
>
> 1. 每次都让 nums[rihgt] 进窗口，当nums[rihgt] == 0 时，让0的个数加1；
> 2. 当0的个数大于k时，left找到第一个为0的位置，跳过去，并让0的个数减1；
> 3. 最后更新结果。
> 4. 为什么可以用滑动窗口：
>    - 当0的个数大于k时，对于left到非0前的所有元素来说已经是最大的连续的1的个数了；
>    - 因此right不用会退了，只要让left到第一个0元素的下一个位置即可。



### 3. 实现代码

```c++
class Solution 
{
public:
    int longestOnes(vector<int>& nums, int k) 
    {
        int left = 0, right = 0;
        int ans = 0;
        int zero = 0;
        for (right = 0; right < nums.size(); ++right)
        {
            // 1. 进窗口
            if (!nums[right])
            {
                ++zero;
            }
            // 2. 出窗口
            while (zero > k)
            {
                if (nums[left] == 0) --zero;
                ++left;
            }
            ans = max(right - left + 1, ans);
        }
        return ans;
    }
};
```
